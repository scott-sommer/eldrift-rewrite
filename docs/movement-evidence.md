### Combined movement service
createMovementService now composes explicit room policy, body/load-derived terrain costs, shared matrix snapshots, bounded path caching, stuck tracking, transition geometry, and one traffic dispatcher. Path requests retain their own search callback through a WeakMap, avoiding ambient matrix context across movers. Traffic legality checks local/landing static obstacles, terrain, transition consistency and mapped room connectivity; observed occupancy includes hostile creeps and power creeps in visible rooms.
