## Topology identity correction

The first combined diagnostic exposed unnecessary quotation changes when a room moved between live and retained visibility. The old version encoded those representations differently even when static costs were equal. Matrix snapshots now expose per-room versions; remote quotation builds a canonical sorted room/topology identity in either representation. Existing general snapshot-version behavior remains available to other callers.

Equal static costs across lost/restored vision therefore reuse the quote identity. Genuine obstacle differences still invalidate it, including conservative differences in retained infrastructure. This does not invent empty unseen corridors or bypass traversal freshness. Existing opaque cache identities may be remeasured after the algorithm change; envelope formats are unchanged. Unit regression independently verifies identity stability and real topology invalidation.

The initial unconstrained multi-room trial recorded3120 deliveries against6550 birth expenditure and cancelled early births. It is retained as a diagnostic. Both admission scope and topology normalization changed before this final one-outpost qualification; the complete cost difference cannot be attributed to only one of them. Dynamic multi-room startup/churn still needs separate assessment.
