# Current forecast-to-birth admission

ED-29 remains In Progress. The remote birth-policy boundary now has an optional read-only admit(profile, request, currentConfig) callback. Final fleet dispatch checks it after current ownership/body/lease and selected-placement validation, before route/native spawn admission. Missing callback preserves ordinary behavior. Recruitment prepare is never invoked by the final gate.

createStartupForecastAdmission reuses the existing completed startup planning job. It does not create a namespace, run simulator frames, publish requests, reserve money or invoke a game action. Its caller supplies current query, return policy, binding and tick. It requires the profile home/source/room/generation, current tick and binding to match the query; incomplete/expired/mismatched evidence refuses. It assesses the completed result under the supplied current return thresholds and requires all modeled cohort participants and household labor. Only an exact participant request at its modeled absolute start frame can pass. Request identity, owner, body, population home, boost/admission metadata, placement, priority and ready/expiry clocks use the common spawn-request comparator; relative forecast clocks are bound to the observation epoch.

A late or changed request cannot borrow another approved slot. The current return threshold is assessed again, so a previously positive result does not override a stricter current policy. Shared fleet safety, enabled policy, assignment ownership, routing, physical spawn payment and native dispatch remain independent gates. The callback is an application integration point, not permission to bypass them.

The caller is responsible for freshly deriving the binding from configuration, topology/traversal, selected strategy and relevant world context. Supplying the old stored binding back to itself does not establish freshness. This increment implements the request/economic fence and its dispatch hook; it does not yet implement automatic current binding derivation, world strategy generation, default production economic adoption or an approved-cohort publication journal. Completed scratch evidence may be replaced by another planning job, in which case this fence refuses until compatible evidence is available again. Durable multi-candidate approvals and shared-capital scheduling remain separate work.
