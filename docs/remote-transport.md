# Dedicated remote energy transport

ED-29 remains in progress. This component composes existing hauling, quantity reservations, transfer confirmation, movement and home banking; it does not register an automatic remote manager in the main loop.

The recruited actor must match its explicit home and owner. Each trip encodes its mine demand and assignment generation. Current lease resolution fences collection and delivery; revoked trips reconcile outstanding confirmations, release their own claims and return cargo through home banking. Loaded couriers may escape an unsafe origin along an admitted home corridor while new collection remains suspended. Unknown confirmations hold rather than inventing delivery credit.

Live source candidates are energy containers within two tiles and energy drops within three tiles of the retained source position. These distances preserve the active role.courierV3 source-discovery behavior. Selection uses actual stock; legacy future-production predictions never become reservable physical stock. Shared quantity pools replace courier earmarking. Existing trips retain their selected valid endpoint when candidate rankings change. Native pickup quantities cannot be capped, so admission preserves the full native pickup minimum alongside the configured batch minimum.

Shared task submission checks unresolved journals, queue capacity and actual source/sink availability before publishing a task. Failed persistence cancels the producer request and releases its quantity scope. A dynamically supplied hauling route checks each collection/delivery leg; existing static-route callers retain their interface.
