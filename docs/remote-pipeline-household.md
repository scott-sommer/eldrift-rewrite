A current workforce proposal publishes one balanced WORK/CARRY/MOVE body through the checked identity/task/queue journal. Ordinary full-bot dispatch rechecks authority and pays200 using explicit spawn-first energy order. Home work goes first; distributor recruitment enables at10. Scouts, extraction, hauling, reservation, replacement and withdrawal then use the ordinary runtime. A supplied home road site has3 progress remaining.

The home worker becomes active10, picks up3, builds3 and records completion12. Productive home work/recruitment disable afterward; a controlled no-energy movement parks the empty worker at43,24 by16, where it remains idle. This is the stated post-task policy, not an assumed zero-cost stream of future jobs. The distributor actually refills spawning structures from storage; internal redistribution is traced separately and never credited as source income. Remote withdrawal starts800 while cargo is loaded, then completes before the horizon with no remote cargo/tasks/pending births/quantity/mining claims.

## Failure and correction

The first clean run at2d10828 failed because the home worker never appeared: ordinary worker recruitment cancelled its guarded request when the standard builder recipe could not fit the200 budget. The independently published balanced recipe was valid at200. The failed raw run, empty labor observations and verifier error remain archived as failed; remote extraction continuing did not qualify this combined case.

The correction separates producer ownership in population demand. Injected externally-owned pending requests count as reserved spawning units but are excluded from ordinary cancellation. Worker recipe/target/enable cleanup preserves guarded births, leaving revocation to their publisher and final admission. This also prevents a second ordinary worker from filling demand already covered by the guarded birth. Targeted tests cover coexistence with a higher-priority ordinary request, unaffordable recipes, disabling and target reduction. Ordinary unguarded recruitment retains existing behavior.
