# Courier phase and guard diagnostics

Implementation: 544b57a. Optional synchronous scopes report courier current-demand, head, settlement, authority, source, collection, sinks, admission, execution and whole-run begin/end phases. A refusing guard emits the current courier phase; fleet execution also records an actor yield after any internal budget refusal. No diagnostic changes the guard result, task state or financial decision. Disabled scopes retain the original guard; ordinary economic composition omits the absent callback.

The `--courier-probe` flag uses the configured 5ms case, stops at 260 ticks and captures at most 600 rows during ticks 200–240. This is deliberately bounded timing evidence; it does not pass a forecast extending beyond 800. Instrumentation consumes CPU and can affect scheduling. A full untraced campaign remains the qualification check.
